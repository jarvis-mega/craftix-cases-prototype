# Craftix — три локальных интерактивных прототипа

Это независимые браузерные демо, **не** Craftix production. Нет аккаунта, сервера и реальных платежей; прогресс каждого прототипа хранится в `localStorage` текущего origin.

## Запуск и проверка

```bash
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.mjs
```

Откройте локально:

- Кейсы: `http://127.0.0.1:8765/`
- Конечная рулетка: `http://127.0.0.1:8765/roulette/`
- Случайные фрагменты: `http://127.0.0.1:8765/fragments/`

Подойдёт любой статический HTTP-сервер. Через `file://` модули и `localStorage` могут быть заблокированы. Публичных ссылок в этом репозитории нет: публикация выполняется отдельно после ревью.

## Что нажать для полного цикла

1. **Кейсы:** «Открыть 1» или «Открыть 10», затем «Пропустить» при желании. Для быстрого просмотра G и гарантии откройте «Посмотреть сценарий», подготовьте нужный сценарий и **сами** нажмите «Открыть 1». Открывать кейс можно бесконечно.
2. **Рулетка:** «Крутить рулетку» четыре раза: выигранные призы исчезают, цена идёт 100 → 200 → 400 → 800 ◆. После ранней G можно остановиться или продолжить. Для финала за один клик подготовьте «Последнее вращение / завершение» в панели сценариев и затем **сами** нажмите основную кнопку.
3. **Фрагменты:** выбирайте валюту и нажимайте основную кнопку, пока не будет 100 фрагментов; затем вручную нажмите «Собрать G». В панели сценариев «Достижение порога» готовит 98 и +2 для следующего нажатия, «Сборка с остатком» готовит 105 для следующего нажатия. Режим A сохраняет остаток, режим B конвертирует его в D и закрывает цель до перезапуска.

Везде рядом с балансом есть «+ Пополнить»: +1 000/+5 000/+10 000 демо-кристаллов; в кейсах и фрагментах — +10 тестовых билетов. Пополнение не сбрасывает прогресс. «Начать демо заново» — отдельное действие. «Как это работает» отвечает на вопросы о результате, случайности, повторах, прогрессе и завершении. Переключатель обычной/быстрой анимации и «Пропустить» меняют только показ.

## Неизменные правила и сохранение

- Кейсы: R1 50%, R2 30%, R3 15%, R4 3%, G 2%; 100 ◆/1 билет за 1, 1 000 ◆/10 билетов за 10. Награды остаются в пуле, гарант G на 80-м открытии без G, x10 рассчитывается последовательно.
- Рулетка: четыре награды без повторов, равные шансы оставшихся секторов 25% → 33⅓% → 50% → 100%; цены 100/200/400/800 ◆.
- Фрагменты: +2 (80%), +5 (18%), +20 (2%); 100 ◆ или 1 билет за попытку; сбор G за 100 фрагментов. Остаток в режиме A сохраняется, в B конвертируется 1:1 в D.

Движки изменены только для **размеров тестового пополнения** и **меток демонстрационного сценария/сборки**. Логика выбора, вероятности, цены, гарант и списания не менялись; это проверяют тесты трёх движков. Результат фиксируется до анимации. Перезагрузка показывает уже сохранённый результат без повторной выдачи или списания; пропуск не перебрасывает результат. Быстрые сценарии — локальные тестовые вмешательства, отмеченные «ДЕМО» или «ТЕСТ».

## Ограничения

Состояние не защищено от ручного изменения через DevTools. Две вкладки не синхронизируются транзакционно. Демо не связано с реальным аккаунтом и ничего не публикует.
