# Craftix — «Кейсы» (браузерное демо)

Самостоятельный интерактивный прототип. Не подключён к Craftix, платёжной системе, Gateway или серверу. Данные хранятся только в `localStorage` браузера для текущего origin.

## Запуск

Из этой директории:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`. Подойдёт любой статический HTTP-сервер; сборка и установка пакетов не нужны. Не рекомендуется открывать `index.html` через `file://`: ES-модули и `localStorage` могут блокироваться браузером.

Тесты:

```bash
node --test tests/*.test.mjs
```

Нужен Node.js 18+ (`structuredClone` и встроенный `node:test`).

## Механика

- Один кейс можно открывать сколько угодно; награды не удаляются из пула. Шансы обычного открытия: R1 50%, R2 30%, R3 15%, R4 3%, G 2%.
- Ресурс выбирается явно. Цена: 100 кристаллов или 1 билет за открытие, 1 000 кристаллов или 10 билетов за набор. Если выбранного ресурса не хватает на весь набор, ничего не списывается и не выдаётся; переключения ресурса нет.
- Счётчик неудач общий для обоих ресурсов. После 79 открытий без G следующее, 80-е, гарантирует G. Ранний G сразу сбрасывает счётчик. Набор из 10 рассчитывается последовательно, и в нём может быть несколько G.
- Сначала рассчитываются все награды и одним сохранением фиксируются баланс, коллекция, история и результат. Анимация только показывает уже сохранённое. «Пропустить» не меняет результаты. После перезагрузки незавершённая анимация заканчивается показом результата без повторного списания/выдачи.
- Панель «Тестирование» отдельно от игрового блока: пополнение, счётчик 79, одноразовый принудительный G, полный сброс. Принудительный G помечается «ТЕСТ»; если при этом гарант тоже был активен, это отмечено отдельно.
- История хранит последние 40 операций; коллекция хранит общие количества. Выбранный радиопереключатель оплаты после перезагрузки возвращается к кристаллам; баланс/история/счётчик/результат сохраняются.

## Файлы

- `index.html` — семантическая русская разметка.
- `styles.css` — кубический визуал, адаптивная сетка, фокус и reduced-motion.
- `app.mjs` — DOM, выбор оплаты, управление анимацией и тестовой панелью.
- `engine.mjs` — чистая модель наград, шансы, гарант, цены и переходы состояния.
- `storage.mjs` — чтение/однократное сохранение состояния и сброс.
- `tests/engine.test.mjs` — детерминированные проверки движка и хранения.
- `README.md` — эти инструкции.

## Ограничения демо

Состояние локальное и не защищено от ручного изменения через DevTools. Открытие в двух вкладках одновременно не синхронизируется транзакционно; это не серверная игровая экономика. Результаты не экспортируются и не связаны с реальным аккаунтом.
